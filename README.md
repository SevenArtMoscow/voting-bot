# 🤖 Бот для голосования

Полнофункциональный Telegram бот для проведения голосований с системой регистрации, CAPTCHA и админ-панелью.

## 🚀 Возможности

### Для пользователей:
- ✅ Регистрация с проверкой CAPTCHA
- 🗳️ Голосование за кандидатов
- 🔒 Защита от повторного голосования
- 📱 Удобный интерфейс

### Для администратора:
- 📊 Полная статистика голосования
- 👥 Управление пользователями
- 🗳️ Просмотр всех голосов
- 🏆 Объявление победителя
- 📥 Экспорт данных в CSV
- 🔄 Сброс голосования

## 📋 Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd vote-bot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте бота:**
   - Откройте файл `config.py`
   - Замените `YOUR_BOT_TOKEN_HERE` на токен вашего бота
   - При необходимости измените ID администратора

4. **Запустите бота:**
```bash
python bot.py
```

## ⚙️ Конфигурация

### Основные настройки в `config.py`:

```python
# Токен бота (получите у @BotFather)
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# ID администраторов
ADMIN_IDS = [802373523, 665509323]

# Кандидаты для голосования
CANDIDATES = [
    {"id": 1, "name": "Петров Матвей Владимирович", "emoji": "👨‍💼"},
    {"id": 2, "name": "Пупликов Валентин Александрович", "emoji": "👔"},
    # ... другие кандидаты
]
```

## 🎯 Команды

### Для всех пользователей:
- `/start` - Начать работу / Регистрация
- `/myid` - Узнать свой Telegram ID
- `/help` - Показать справку

### Для администратора:
- `/admin` - Админ панель
- `/stats` - Полная статистика
- `/users` - Список пользователей
- `/votes` - Детальные голоса
- `/addvotes` - Накрутить голоса
- `/removevotes` - Отнять голоса
- `/announce` - Объявить победителя
- `/export` - Экспорт данных
- `/reset` - Сброс голосования
- ⏸️/▶️ Остановить/Запустить голосование (в админ панели)

## 🗄️ База данных

Бот использует SQLite для хранения данных:

- **users** - зарегистрированные пользователи
- **votes** - голоса пользователей
- **results** - результаты голосования (включая накрученные голоса)
- **captcha_sessions** - сессии CAPTCHA
- **settings** - настройки системы
